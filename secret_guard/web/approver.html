    本设备的配对信息

    把以下内容保存为文件，分别交给服务器管理员（device-register）和注入工具（pair-approver）。只含公钥。

    原型：密钥和密码保存在浏览器存储中，保护弱于系统安全区。请只用假凭据。
    

    注入工具
      配对一台注入工具
      粘贴注入工具 pairing 命令生成的内容。请当面核对设备编号。
      

      密码
        添加或更新密码
        密码内容由你自己管理。本设备不检查它的格式或长度，只按原样保存，批准时密封并转发给注入工具。别名用来区分每一条密码。
        为已有密码添加副本
        同一个别名可以保存多个副本，例如同一服务的多个 API key。审批时可以选择返回哪一个。
        保存后，本设备把每条密码编译成匹配程序（长度、哈希标记、加盐摘要）下发给注入工具，明文不离开本设备。agent 读到含密码的内容时会触发审批。
        

        审批模式
        自动审批规则
        符合规则的请求自动批准，每一项都可以用 * 通配。例如：类型 fill，密码 DEEPSEEK_*，工具 Write，目标 */.codex/config.toml。本页开着并已连接时才生效。
          

          待审批
          先连接服务器，再获取待审批请求。
          已自动拒绝的请求
          本设备确定不能批准的请求（没有这个密码、注入工具未配对、仓库不在允许范围等）会立即拒绝，并把原因告诉调用方。
